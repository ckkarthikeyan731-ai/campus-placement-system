# Campus Placement Management System

Desktop application for managing student placement records, built with Java Swing and MySQL.

**Author:** Karthikeyan C K · 25IT347  
**Institution:** St. Joseph's College of Engineering

## Features

- Dashboard KPIs for student totals, placed / not placed counts, average placed package, and top placed package.
- Search, department/status filters, and sortable placement records.
- Add, update, and delete records with validation and delete confirmation.
- Export the current table view to CSV.
- Login screen, live clock, and status feedback.
- Responsive Swing layout; no additional Java packages or build tools required.

Package KPIs use records with status **Placed**. Search and filters change the table view, not the overall dashboard totals.

## Requirements

- Java 11 or later (JDK, so `javac` is available)
- MySQL 8
- MySQL Connector/J 8.3.0, included at `lib/mysql-connector-j-8.3.0.jar`

## Setup

1. Create the database and sample records by running `database_setup.sql` in MySQL:

   ```cmd
   mysql -u root -p < database_setup.sql
   ```

2. Configure database connection variables if your local MySQL settings differ. In Command Prompt, set them before launching:

   ```cmd
   set CPS_DB_USER=root
   set CPS_DB_PASS=your_mysql_password
   run.bat
   ```

   Optionally set `CPS_DB_URL` to override the default JDBC URL. These variables are read by the application and are not stored in source control.

3. Run `run.bat`. It compiles the source and starts the application from its own project folder.

4. Sign in with the development account created by the SQL script:

   | Username | Password |
   |----------|----------|
   | `admin` | `admin123` |

   Change the default admin password before using this with real data. This project is a local academic demonstration, not a production authentication system.
